# Курсовая работа. ООП

## Описание:
Программа, которая получает информацию о вакансиях с платформы hh.ru в России,
сохраняет их в файл и позволять удобно работать с ними: 
добавлять, фильтровать, удалять.
## Реализация:
1. Реализован абстрактный класс для работы с API сервиса с вакансиями
```
    class AbstractApiHh(ABC)
```
2. Реализован класс, наследующийся от абстрактного класса, для работы с платформой hh.ru
   (класс умеет подключаться к API и получать вакансии)
```
    class GetApiHh(AbstractApiHh)
```
3. Реализован класс для работы с вакансиями. Класс поддерживает методы сравнения вакансий между собой 
по зарплате и валидирует данные, которыми инициализируются его атрибуты.
```
    class Vacancy
```
4. Реализован абстрактный класс и класс для сохранения информации о вакансиях в JSON-файл.
```
    class AbstractJsonSaver(ABC)
    class JsonSaver(AbstractJsonSaver)
```
5. Все классы объединены в единую программу и созданы вспомогательные функции для взаимодействия с пользователем.
```
    if __name__ == "__main__":
        user_interaction()
```
Добавлена обработка возможных исключений. На функционал написаны тесты.

## Тестирование:
Тесты проверяют корректность работы Классов. Примеры тестов:
```
def test_vacancy_initialization():
    vacancy = Vacancy("Python Developer", 100000, 150000, "https://hh.ru/vacancy/123456", "Moscow")
    assert vacancy.name_vacancy == "Python Developer"
    assert vacancy.salary_from == 100000
    assert vacancy.salary_to == 150000
    assert vacancy.url == "https://hh.ru/vacancy/123456"
    assert vacancy.city == "Moscow"
```

```
def test_repr():
    # Создаем экземпляр класса с известными данными
    api = GetApiHh()
    api._all_vacancy = [{"name": "Вакансия 1"}, {"name": "Вакансия 2"}]

    # Ожидаемая строка представления
    expected_repr = "[{'name': 'Вакансия 1'}, {'name': 'Вакансия 2'}]"

    # Проверка, что __repr__ возвращает ожидаемую строку
    assert repr(api) == expected_repr, f"Ожидалось: {expected_repr}, Получено: {repr(api)}"
```
